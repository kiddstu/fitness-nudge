Not a skill. Three hooks.

A skill is instructions to the model, so it depends on the model remembering — and it drifts within a few turns. These are executed by the harness and fire whether the model is paying attention or not.

The bundled /fit skill only handles the parts that need judgment: tallies, tuning, picking a gentler list.

EventWhat happens
UserPromptSubmitIf the cooldown has elapsed, picks an exercise, logs it, speaks it, and tells Claude to announce it.
NotificationGlass beep. Claude wants your input.
StopTink beep, only if a nudge is still outstanding.

The nudge path always exits 0. Exit code 2 on UserPromptSubmit blocks the prompt, so a bug there could stop you talking to Claude at all. Audio is backgrounded too. Hooks are synchronous, and an unbackgrounded say would stall your turn until it finished speaking.

macOS, Linux and Windows.

The exercise, the log and Claude's spoken announcement are platform-independent. Only the audio differs.

PlatformBeepSpoken exercise
macOSafplay, built insay, built in
WindowsSystemSounds, built inSystem.Speech, built in
Linuxpaplay, canberra-gtk-play or pw-playespeak-ng, install one

Linux is the only platform where voice needs anything installed: sudo apt install espeak-ng. Windows needs bash on PATH, which Git for Windows provides; WSL is detected and routed through PowerShell, since Windows audio is more reliable there than Linux audio.

Missing audio is never fatal. With no player and no voice you still get the exercise announced in text, logged and tallied.

What it does not do.

The hooks fire in every project, not just one. To scope them, guard on $CLAUDE_PROJECT_DIR inside the nudge case in scripts/claude-fitness.

CI runs every push across macOS, Windows and Ubuntu, and covers all three hook paths, the cooldown, the pending marker, the kill switch, the 7-day report window and the set-confirmation log. It does not cover audible playback: the runners are headless with no audio sink, so what is verified is that the right player and speech engine are detected and invoked, not that a sound came out of a speaker.

It does not track you, phone home, or sync anything. The log is a TSV file on your disk.
